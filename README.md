# KinoBuddy

Веб-портал, где люди находят компанию, чтобы вместе сходить в кино. Город запуска — Штутгарт.

Главная идея: знакомство строится не вокруг анкет, а вокруг **конкретного сеанса**. Пользователь выбирает фильм в афише и публикует приглашение, другие откликаются, автор принимает отклик, и открывается чат.

Техническое задание: [docs/TZ.md](docs/TZ.md).

## Что уже работает (MVP)

- Регистрация и вход по e-mail (только 18+), сессии в HttpOnly-cookie.
- Анкета: имя, возраст, пол, **район Штутгарта** (вместо геолокации), жанры, любимые фильмы, язык показа, формат встречи, радиус поиска.
- Страница пользователя: без e-mail, даты рождения и координат.
- **Кинотеатры**: поиск по названию и по радиусу (1–50 км) от района из анкеты, сортировка по расстоянию.
- **Афиша** на 14 дней: фильтры по дате, радиусу, кинотеатру, фильму, OV/OmU.
- **Приглашения**: из афиши или вручную, формат «вдвоём / компанией», число мест, кто покупает билеты.
- Лента приглашений рядом, отклики, принятие и отклонение, автоматическое закрытие при заполнении мест.
- **Чат**: только для автора и принятых участников.
- Безопасность: блокировка, жалобы, админка жалоб и бан, удаление аккаунта, ограничение частоты запросов, CSP.
- Парсинг афиши: каркас адаптеров, универсальный парсер schema.org `ScreeningEvent`, проверка robots.txt.
- Импорт кинотеатров из OpenStreetMap и описаний фильмов из TMDB.

## Стек

- **TypeScript** везде; Node.js ≥ 22.13.
- Сервер: встроенные `node:http` и `node:sqlite`, **без runtime-зависимостей**.
- Сайт: одностраничное приложение на TypeScript без фреймворков, компилируется в `public/js`.
- Тесты: `node:test` (18 тестов, включая сквозной сценарий через API).

## Запуск

```bash
npm install          # только typescript и @types/node
cp .env.example .env # при желании поменять настройки
npm run dev          # сборка и запуск → http://localhost:3000
```

При первом запуске (`SEED_DEMO=1`) база заполняется кинотеатрами Штутгарта, **вымышленной демо-афишей** и четырьмя демо-пользователями:

| E-mail | Пароль |
|---|---|
| anna@demo.kinobuddy | demo-pass-123 |
| max@demo.kinobuddy | demo-pass-123 |
| lena@demo.kinobuddy | demo-pass-123 |
| oleg@demo.kinobuddy | demo-pass-123 |

> В продакшене поставьте `SEED_DEMO=0` и удалите демо-аккаунты.

Чтобы стать администратором, укажите свой e-mail в `ADMIN_EMAIL` **до** регистрации. Жалобы — на странице `#/admin`.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сборка и запуск |
| `npm test` | Сборка и все тесты |
| `npm run import:osm` | Обновить кинотеатры и точные координаты из OpenStreetMap |
| `npm run tmdb:enrich` | Подтянуть описания, постеры и жанры из TMDB (нужен `TMDB_API_KEY`) |
| `npm run scrape` | Один раз запустить парсеры афиши |
| `npm run seed:demo` | Добавить демо-данные вручную |

## Как подключить реальную афишу

1. Откройте страницу расписания на сайте кинотеатра и посмотрите исходный код. Если там есть `<script type="application/ld+json">` с `"@type": "ScreeningEvent"`, подойдёт готовый адаптер `jsonld`.
2. Впишите URL в `config/scrapers.json` и поставьте `"enabled": true`.
3. Проверьте: `npm run build && npm run scrape`.
4. Если разметки нет, напишите адаптер в `src/server/scrapers/` (функция возвращает `{ movieTitle, startsAt, language, ticketUrl }[]`) и добавьте его в `ADAPTERS` в `run.ts`.
5. Включите автоматический парсинг: `SCRAPE_ENABLED=1` (по умолчанию раз в 6 часов).

Перед этим проверьте правила использования сайта, а лучше договоритесь с кинотеатром о фиде. Сеансы, пропавшие из источника, помечаются отменёнными, а не удаляются. Пустой ответ ничего не отменяет (скорее всего, сломался парсер).

## Структура

```
docs/TZ.md                 техническое задание
config/scrapers.json       источники афиши
public/                    index.html, styles.css, (js/ — результат сборки)
src/server/
  index.ts, app.ts         запуск, HTTP, статика, заголовки безопасности
  db.ts                    схема SQLite
  auth.ts                  пароли (scrypt), сессии
  geo.ts                   районы Штутгарта, расстояния
  routes/                  auth, catalog (кинотеатры/афиша), invitations (+чат), users (+жалобы/админ)
  scrapers/                парсеры афиши, robots.txt, импорт сеансов
  integrations/            OpenStreetMap, TMDB
  seed.ts                  кинотеатры и демо-данные
src/web/                   сайт (SPA): router, api, views/*
test/                      тесты
```
